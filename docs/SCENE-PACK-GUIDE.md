# Flow 景色パックの作り方

Flow に、自分で作った景色を**プログラミングなしで**足すための手引きです。
景色は `pack.json` という1つのテキストファイル（JSON）で書きます。Flow を作り直す必要はなく、フォルダーに置くと数秒で使えます。

- **desk 背景** … 壁紙の景色（画面いっぱいに描く空・風景）
- **task 背景** … タスクバー（Mac では Dock）の景色（画面の下の細い帯に描く地面・街・波）
- **パック** … 景色をまとめた1つのフォルダー（中に `pack.json`）
- **シーン** … 1つの景色（desk か task のどちらか）
- **レイヤー** … シーンを作る重ね絵の1枚。上から順に重なる
- **組み合わせ（pair）** … 「この desk とこの task は似合う」という対。メニューとランダムに出る

---

## 1. 5分でできる手順

道具は `flowpack`（Windows は `flowpack.exe`、Mac は `Flow --check-pack` / `Flow --preview-pack`）です。

```
flowpack new  "C:\パックの置き場所\my-pack"            ← 作りかけの見本が1つできる
（pack.json を編集する）
flowpack check   "C:\パックの置き場所\my-pack"          ← 間違い探し。RESULT: OK が出るまで直す
flowpack preview "C:\パックの置き場所\my-pack" "C:\絵"  ← 絵（PNG）を出して、目で見る
flowpack install "C:\パックの置き場所\my-pack"          ← Flow に入れる（packs フォルダーへコピー）
```

入れたあと、数秒で Flow のメニューに出ます（再起動は要りません）。
手で入れるなら、フォルダーごと `packs` フォルダーに置くだけです。

- Windows … Flow のフォルダーの `packs`（トレイのメニュー「追加パックのフォルダーを開く」）
- Mac … `~/Library/Application Support/Flow/packs`（メニューバーの「追加パックのフォルダーを開く」）

`packs\（パックごとのフォルダー）\pack.json` という形にします。

---

## 2. pack.json の形（最小）

```json
{
  "format": 1,
  "name": "パックの名前",
  "author": "作った人（空でもよい）",
  "scenes": [
    {
      "id": "my-sky",
      "kind": "desk",
      "title": "私の空",
      "layers": [
        { "type": "gradient", "top": "#0a1030", "bottom": "#3a2a5a" }
      ]
    }
  ],
  "pairs": []
}
```

守ること（JSON の決まり）:

- 文字は必ず**半角のダブルクォート `"`** で囲む。シングルクォートは使えない。
- **コメント（`//` や `/* */`）は書けない。**
- 最後の項目のあとに**カンマを付けない**（`}` や `]` の直前のカンマはエラー）。
- 項目と項目のあいだには、必ずカンマを入れる。
- 数字は引用符で囲まない（`"count": 3`。`"count": "3"` は間違い）。
- **知らないキーを書くとエラー**になる（打ち間違いを見逃さないため）。

---

## 3. シーン

| キー | 内容 |
|---|---|
| `id` | 半角の小文字・数字・`-` だけ、2〜32文字、先頭は小文字。例 `sunset`。組み込みの名前（`stars` `river` など）と他のパックの id と**かぶってはいけない** |
| `kind` | `"desk"`（壁紙）か `"task"`（タスクバー／Dock） |
| `title` | メニューに出る名前（日本語でよい。1〜60文字） |
| `layers` | レイヤーの並び（1〜16枚）。**先に書いたものが奥、あとに書いたものが手前** |

1パックにシーンは40個まで、組み合わせは60個まで。

---

## 4. 色の書き方

- `"#ff8800"` … 6桁の16進（`"#f80"` の3桁も可）
- `"@dark"` `"@mid"` `"@light"` `"@spark"` … Flow の「色（パレット）」設定と、時刻による色の変化に**合わせて変わる色**。「環境に馴染ませたい」ときに使う

固定したい絵は `#rrggbb`、メニューの色設定に従わせたいところだけ `@…` にする、が基本です。

---

## 5. 場所・大きさ・速さの決まり

- **横方向はピクセル（px）、縦方向は 0〜1 の割合**です（0＝上、1＝下）。
- 景色は**2px 角のドット**で描かれます（ドット絵風）。`size: 1` は 2px、`size: 2` は 4px。
- 速さは **px/秒**。
- **角度**（`angle`）は 0＝右へ、90＝下へ、180＝左へ、270＝上へ。
- 複数のモニターは**1枚の長い絵**としてつながります。`x` などの「横の割合」は、全モニターを並べた全体の幅に対する割合です。
- task の帯はとても細い（Windows のタスクバーで約 48〜64px、Mac の Dock で約 64〜100px）。縦の位置は帯の高さに対する割合なので、**どんな高さでも崩れません**。

---

## 6. レイヤーの種類（全部で6つ）

どのレイヤーにも共通で `"alpha"`（0〜1、透け具合。省略は 1）が書けます。
（`gradient` 以外は `"seed"`（0〜100000）も書けます。同じ種類のレイヤーを2枚重ねて、粒の配置を変えたいときに数字を変えます）

### 6-1. gradient（グラデーション。空の下地に使う）

| キー | 範囲 | 意味 |
|---|---|---|
| `top` ※必須 | 色 | 上の色 |
| `bottom` ※必須 | 色 | 下の色 |
| `from` | 0〜1（省略 0） | 塗り始め（割合） |
| `to` | 0〜1（省略 1） | 塗り終わり。`from` より大きく |

```json
{ "type": "gradient", "top": "#2a1a5e", "bottom": "#d9786a", "from": 0, "to": 0.6 }
```

desk シーンは**最初の1枚を、全面の gradient（from 0 〜 to 1、alpha 1）**にします。無いと壁紙が真っ黒になります（check が注意を出します）。
2色より多い空にしたいときは、gradient を縦に並べます（上の `bottom` と下の `top` を同じ色にすると、つなぎ目が見えません）。

### 6-2. particles（粒。星・雪・雨・蛍・火の粉・流れ星）

| キー | 範囲 | 意味 |
|---|---|---|
| `count` | 0.01〜60 | 粒の数。**横 1000px × 縦 100px あたりの個数**。少なくとも1個は出る |
| `size` | 1〜6 | 粒の大きさ（ドット数） |
| `shape` | `dot` `square` `plus` `streak` | 点／四角（`dot` と同じ）／十字／尾を引く線 |
| `color` ※必須 | 色、または色のリスト（8個まで） | リストなら粒ごとに選ぶ |
| `speed` | `[最小, 最大]`（0〜600） | 速さ（px/秒）。数字1つなら固定 |
| `angle` | 0〜360 | 進む向き |
| `sway` | 0〜80 | 横へのゆれ幅（px） |
| `swayRate` | 0.05〜10 | ゆれる速さ |
| `twinkle` | 0〜1 | またたき（明るさの変化の大きさ） |
| `twinkleRate` | 0.05〜10 | またたく速さ |
| `y` | `[上, 下]`（0〜1） | 粒がいる縦の範囲（ここで折り返して回り続ける） |
| `length` | 2〜200 | `streak` の尾の長さ（px） |

```json
{ "type": "particles", "count": 4, "size": 1, "shape": "dot", "color": ["#ffffff", "#ffe9a8"],
  "speed": [1, 3], "angle": 0, "twinkle": 0.8, "y": [0, 0.8] }
```
雪: `angle` 80〜100・`speed` [15, 40]・`sway` 6。雨: `shape` `streak`・`angle` 100・`speed` [300, 500]。

### 6-3. wave（波・水面）

水面の高さが波打つ帯を、その下まで塗ります。

| キー | 範囲 | 意味 |
|---|---|---|
| `y` | 0〜1 | 水面の高さの基準（割合） |
| `amp` | 0〜0.5 | 波の高さ（割合） |
| `wavelength` | 20〜4000 | 波の長さ（px） |
| `speed` | −400〜400 | 流れる速さ（正は右へ、負は左へ） |
| `color` ※必須 | 色 | 水の色 |
| `foam` | 色（省略可） | 水面の線の色（白い波がしら） |

波は2〜3枚重ねる（奥ほど薄く・遅く・波長を長く、手前ほど濃く・速く・短く）と立体的になります。

### 6-4. silhouette（地面・山・木・ビル）

「上の縁が波打つ地面」を作り、その縁の上に木やビルを立てます。縁より下は、帯の底まで塗りつぶされます。

| キー | 範囲 | 意味 |
|---|---|---|
| `base` | 0〜1 | 縁（地面の線）の高さの基準（割合。大きいほど下） |
| `profile` | 1〜6個の `{amp, wavelength, phase}` | 縁の起伏。`amp` 0〜0.6（高さの割合）、`wavelength` 20〜6000（px）、`phase` −100〜100。**`amp` と `wavelength` は必須** |
| `style` | `smooth` `spikes` `blocks` | `smooth`＝なだらかな丘や山、`spikes`＝とがった木、`blocks`＝四角いビル |
| `color` ※必須 | 色 | 塗る色 |
| `lit` | 色（省略可） | 縁の線の色（明るい稜線） |
| `spacing` | 6〜400 | 木やビルの間隔（px） |
| `height` | `[最小, 最大]`（0.01〜0.9） | 木・ビルの高さ（帯の高さに対する割合） |
| `width` | `[最小, 最大]`（2〜300） | 木・ビルの幅（px） |
| `window` | 色（省略可） | `blocks` の窓の色 |
| `windowDensity` | 0〜1 | 窓が点いている割合 |
| `scroll` | −200〜200 | 横へ流れる速さ（px/秒。0 で動かない） |

```json
{ "type": "silhouette", "style": "spikes", "base": 0.85, "color": "#0b1a14", "spacing": 22,
  "height": [0.3, 0.6], "width": [10, 18], "profile": [ { "amp": 0.04, "wavelength": 500, "phase": 0 } ] }
```
奥の景色を先に、手前を後に書き、奥は明るく・低く、手前は暗く・高くすると遠近が出ます。

### 6-5. orb（光の玉。太陽・月・街灯のにじみ）

| キー | 範囲 | 意味 |
|---|---|---|
| `x` | 0〜1 | 横の位置（全モニターの幅に対する割合） |
| `y` | −0.5〜1.5 | 縦の位置（割合） |
| `radius` | 4〜600 | 半径（px） |
| `color` ※必須 | 色 | 光の色 |
| `pulse` | 0〜1 | 脈打つ大きさ |
| `rate` | 0.05〜10 | 脈打つ速さ |
| `drift` | −200〜200 | 横へ動く速さ（px/秒） |

### 6-6. sprites（ドット絵の絵柄を流す。鳥・雲・舟・風船）

文字で絵を描きます。`.` と空白は透明、それ以外の文字は `palette` で色を決めます。

| キー | 範囲 | 意味 |
|---|---|---|
| `rows` ※必須 | 1〜24行、各32文字まで | 絵（文字の並び） |
| `palette` ※必須 | `{ "X": "#ffffff" }` | 文字ごとの色。`rows` に出てくる文字は**全部**書く |
| `count` | 0.01〜40 | 個数。**横 1000px あたり**。少なくとも1個は出る |
| `speed` | `[最小, 最大]`（−300〜300） | 横へ動く速さ（正は右へ） |
| `y` | `[上, 下]`（0〜1） | 縦の範囲 |
| `scale` | 1〜4 | 拡大（1 は 1マス＝2px） |
| `bob` | 0〜60 | 上下にゆれる幅（px） |

```json
{ "type": "sprites", "rows": ["X.X", ".X."], "palette": { "X": "#2a1030" },
  "count": 0.6, "speed": [22, 34], "y": [0.2, 0.55], "bob": 4 }
```

---

## 7. desk と task の作り分け

**desk（壁紙）**
1. 最初に全面の `gradient`（空の色）。
2. 光の玉（`orb`）、星や雪（`particles`）、雲や鳥（`sprites`）を重ねる。
3. 地面は描かない（地面は task の仕事。壁紙に地面があると、画面に地面が2つに見える）。

**task（タスクバー／Dock）**
1. 帯の**下側だけ**を描く。上は透明のまま（壁紙の空が見える）。
2. `silhouette`（地面・街・山・木）や `wave`（水）を重ねる。
3. 全面の gradient は使わない（壁紙を隠してしまう）。
4. 帯はとても細いので、細かい飾りより**シルエットの形**で見せる。

---

## 8. 組み合わせ（pairs）

```json
"pairs": [ { "name": "夕焼けの松林", "desk": "sunset", "task": "pines-dusk" } ]
```

- `desk` は desk のシーン（自分のパックのものか、組み込みの `stars` `snow` `rain` `fireflies` `sakura` `clouds` `aurora` `meteors` `fog` `lanterns`）。
- `task` は task のシーン（自分のパックのものか、組み込みの `river` `sand` `sea` `mountains` `city` `grass` `snowfield` `forest`）。
- 組み合わせはメニューの「組み合わせ」に並び、**「おまかせ」（ランダム）の候補**にもなります。

---

## 9. よくあるエラーと直し方

`flowpack check` は、どこが悪いかを `scenes[0].layers[2].count` のように場所つきで教えます。

| メッセージの例 | 直し方 |
|---|---|
| `JSON syntax error at line 12, column 5` | その行の前後を見る。カンマの付け忘れ／付けすぎ、`"` の閉じ忘れが多い |
| `unknown key "colour"` | キー名の打ち間違い。「allowed here」に使えるキーが全部出る |
| `must be a number (got a string)` | 数字を `"` で囲んでいる。外す |
| `must be between 1 and 6 (got 9)` | 範囲を超えている。範囲内に直す |
| `bad color "red"` | 色は `"#rrggbb"` か `"@mid"` など |
| `must be [min, max]` | `[10, 30]` のように2つの数字。小さい方を先に |
| `missing` | 必須のキーが無い |
| `the letter 'o' has no color in "palette"` | sprites の `rows` にある文字に、`palette` の色が無い |
| `... is the name of a built-in scene` | `id` が組み込みの名前とかぶっている。別の名前に |
| `scene "x" already exists in another pack` | ほかのパックと `id` がかぶっている |
| `pair ... is not a desk scene` | 組み合わせの `desk`／`task` の指定が逆、または id の綴り違い |

## 10. 見栄えのコツ

- **色は少なく**。1つのシーンで 4〜6 色に絞ると、ドット絵らしく落ち着く。
- **層を重ねる**。奥（明るく・遅く・小さく）→ 手前（暗く・速く・大きく）。
- 動きは**ゆっくり**。壁紙は毎日見るので、`speed` は小さめ（粒 1〜10、雲 6〜12、波 20〜40）。
- 時刻で色を変えたい所は `@dark` `@mid` `@light` `@spark` にする。
- 重くしない。レイヤーは多くても 10 枚くらい、`particles` の `count` は 10 以下を目安に。
- 描けたら必ず `flowpack preview` の絵を見る（desk は 960×540、task は 960×60、組み合わせは重ねた絵）。

---

## 11. 見本

`examples` フォルダーに、そのまま使える完成品が3つあります（`sunset-pines`／`night-town`／`sea-breeze`）。
まず入れて動かし、`pack.json` を少しずつ書き換えるのが一番の近道です。
